# 🛒 HOME-MENU
**Web App per la gestione intelligente di Menu Settimanale, Spesa e Giacenze.**

Questa applicazione nasce per semplificare l'organizzazione domestica, collegando ciò che pianifichi di mangiare con ciò che hai effettivamente in dispensa.

---

## 🚀 Funzionalità Principali

### 📅 1. Menu Settimanale
- Pianificazione dei pasti (Pranzo e Cena) per i 7 giorni della settimana.
- Possibilità di salvare le ricette preferite con i relativi ingredienti.

### 📦 2. Gestione Giacenze (Dispensa)
- Database dei prodotti presenti in casa.
- **Alert di esaurimento:** Notifiche o evidenziazione visiva quando un prodotto scende sotto una soglia minima (es. "Manca il latte!").

### 📝 3. Lista della Spesa Automatica
- Generazione automatica della lista basata sugli ingredienti necessari per il menu settimanale.
- Confronto intelligente: "Se serve la pasta per il menu ma è già in dispensa, non aggiungerla alla spesa".
